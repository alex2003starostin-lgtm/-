# GTDesk

Веб-интерфейс для сотрудников компании: подача заявок в техподдержку, HR, АХО, ИБ, казначейство и другие внутренние службы. Каталог из 106 типов заявок, сгруппированных по 12 направлениям.

## Стек

React + TypeScript + Vite, Tailwind CSS v4, React Router, Zustand (профиль и заявки хранятся в localStorage), Framer Motion, lucide-react.

## Запуск

```bash
npm install
npm run dev
```

## Что это за прототип

Это frontend-прототип: заявки сохраняются локально в браузере (localStorage), без реального backend. Для ~17 самых частых заявок (организация рабочего места, доступы, ДМС, визитки, визы и т.д.) реализованы детальные поля формы. Остальные формы используют универсальный движок с полями «Описание», «Приоритет», «Срок», «Вложения».

## Структура

- `src/data/catalog.ts` — каталог отделов/категорий/заявок
- `src/data/formSchemas.ts` — схемы полей для форм
- `src/store/` — профиль пользователя и список заявок (Zustand + persist)
- `src/pages/` — страницы (главная, отдел, форма, подтверждение, мои заявки)
- `src/components/` — переиспользуемые UI-компоненты
