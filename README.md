# GTDesk

Веб-интерфейс для сотрудников компании: подача заявок в техподдержку, HR, АХО, ИБ, казначейство и другие внутренние службы. Каталог из 106 типов заявок, сгруппированных по 12 направлениям.

## Стек

React + TypeScript + Vite, Tailwind CSS v4, React Router, Zustand (профиль и заявки хранятся в localStorage), Framer Motion, lucide-react.

## Запуск

```bash
npm install
npm run dev
```

## Что это за прототип

Это frontend-прототип: заявки сохраняются локально в браузере (localStorage), без реального backend. Для ~17 самых частых заявок (организация рабочего места, доступы, ДМС, визитки, визы и т.д.) реализованы детальные поля формы. Остальные формы используют универсальный движок с полями «Описание», «Приоритет», «Срок», «Вложения».

## Админ-панель

По значку щита в шапке (или `/admin`) открывается раздел для администраторов — демо-режим без реальной авторизации, вход по кнопке. Там можно:

- добавить новую заявку в существующее или новое направление/категорию, с конструктором полей (текст, список, дата, файл и т.д.) и live-предпросмотром;
- удалять добавленные направления/категории/заявки (встроенные из каталога не редактируются).

Добавленные через админку заявки сразу появляются в поиске, на главной и в разделах — каталог собирается на лету из встроенных данных и того, что добавил администратор (localStorage).

## Структура

- `src/data/catalog.ts` — встроенный каталог отделов/категорий/заявок
- `src/data/useCatalog.ts` — хук, объединяющий встроенный каталог с добавленным через админку
- `src/data/formSchemas.ts` — схемы полей для встроенных форм
- `src/store/` — профиль, заявки, добавленный каталог и админ-доступ (Zustand + persist)
- `src/pages/` — страницы (главная, отдел, форма, подтверждение, мои заявки, админка)
- `src/components/` — переиспользуемые UI-компоненты
